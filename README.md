## Features

* Multiple information-gathering features
* Security research utilities
* Testing and educational modules

## Installation

Clone the repository:

```bash
git clone https://github.com/verifyhacker725-glitch/Phoneosint-digix.git
```

Enter the directory:

```bash
cd Phoneosint-digix
```

Give installation permission:

```bash
chmod +x install.sh
```

Run the installer:

```bash
bash install.sh
```
